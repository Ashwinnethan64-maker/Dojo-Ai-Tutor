# DOJO AI — Development Roadmap & Implementation Plan

## Phase Overview & Milestones

| Phase | Milestone Title | Key Deliverables | Status |
|---|---|---|---|
| **Phase 0** | **Audit & Architecture** | Full architectural baseline, specifications, repo initialization, Next.js 15, Tailwind, Supabase, Monaco, FSRS dependencies. | **Active / Complete** |
| **Phase 1** | **Database, Auth & Core Types** | Supabase database migrations, TypeScript domain models, Auth middleware (Email + Google OAuth), RLS policies. | Planned |
| **Phase 2** | **Design System & UI Shell** | Premium Dojo UI aesthetic, Belt theme badges, navigation, modern glass/dark code palette, layout structure. | Planned |
| **Phase 3** | **Python Curriculum & Content Seed** | 18 topics from Introduction to OOP, seed workouts with visible & hidden test cases, starter templates, metadata. | Planned |
| **Phase 4** | **Monaco Coding Workspace & Runner** | Monaco Editor setup, multi-pane layout, execution output terminal, test runner status badges, sandbox connector. | Planned |
| **Phase 5** | **AI Agent Subsystem** | `TutorAgent`, `HintAgent`, `DebuggerAgent`, `MistakeClassifier`, `FlashcardGenerator`, `WorkoutGenerator`. | Planned |
| **Phase 6** | **Mistake Memory & Mastery Engine** | Mistake tracking & fingerprinting, concept mastery calculation algorithm, weakness discovery. | Planned |
| **Phase 7** | **Spaced Repetition Flashcard Player** | FSRS spaced repetition review screen, rating flow (Again/Hard/Good/Easy), interval scheduling. | Planned |
| **Phase 8** | **Adaptive Dashboard & Belt Progression** | Dashboard view, belt elevation checks, streak tracking, XP ledger, weak area recommendations. | Planned |
| **Phase 9** | **Integration, Security, E2E Testing & Polish** | Sentry/PostHog readiness, API rate-limiting, error boundaries, comprehensive validation, build verification. | Planned |
